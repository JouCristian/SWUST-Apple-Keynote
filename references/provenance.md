# Provenance and supplied decks

The public package contains authored demonstrations, not the original historical decks or their media. Use an existing user deck as a reference only when supplied/authorized. Inspect its audience, facts, layout and rights; preserve the original. Do not treat a reference screenshot as reusable stock or current evidence.
