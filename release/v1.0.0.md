# swust-apple-keynote v1.0.0

Draft release notes — prepared locally, not published.

The first public release turns content-first presentation planning into interactive, offline HTML. It includes a persistent shared-element runtime, stateful springs, SVG path tracing, meaningful result settlement, keyboard/notes controls, and a 15-scene Living Showcase.

## Included

- Root-level Skill installation, editable starter and native web runtime.
- Four self-contained offline HTML demos, plus real Showcase screenshots.
- Universal browser quality reporting and focused behavior/material regressions.
- English/Chinese guides, MIT license for original work, and a separate third-party audit.

Download `swust-apple-keynote-v1.0.0-slim.zip`, extract into `.agents/skills/`, then invoke `$swust-apple-keynote`. No JavaScript framework or network access is required for built presentations. Development dependencies are installed separately.

## Scope

Advanced SVG/WebGL material studies use explicit textures and remain Experimental. Browser tests do not establish universal aesthetics, optical accuracy, FPS, assistive-technology compatibility or projector performance. Review the repository's acceptance record and remaining REVIEW items. React Bits component code is not included.
